# Contribute to easy-comb

**English** · [简体中文](../zh/docs/contributing.md)

This page gets a development checkout building and passing tests, and covers the generated parts you must not edit by hand; you need Node.js 22.18 or newer, because the tests run TypeScript directly.
Everyone is welcome to contribute. We only accept patches and features that come with tests.

## Set up and run the checks

Run these in `packages/easy-comb`:

```bash
npm install
npm test               # mocha
npm run typecheck      # tsc
npm run build          # compile to dist/
```

## Run the official test suites

The official WPT, css-parsing-tests, sass-spec and less.js suites check that formatting never crashes, is idempotent and keeps the compiled output unchanged.

1. In `packages/_official_style_suites`, install the dependencies the check uses:

   ```bash
   npm ci
   ```

2. In `packages/easy-comb`, run the check:

   ```bash
   npm run test:official
   ```

   The first run downloads the suites at their [pinned versions](../../_official_style_suites/suites.json) into `.cache/official/` at the repository root.
   The result is compared with the per-suite counts in [test/official-baseline.json](../test/official-baseline.json), 18,461 valid cases in total; see [comb.mjs](../../_official_style_suites/comb.mjs) for what counts as a failure.

## Regenerate the built-in property order

The built-in order in [src/config/sort-order.ts](../src/config/sort-order.ts) is generated by [scripts/sort-order.ts](../scripts/sort-order.ts); never edit it by hand.

```bash
npm run sort-order                    # regenerate after upgrading the data sources
node scripts/sort-order.ts --check    # verify the committed list is up to date
```

When a new property can't be placed automatically, the script fails with a hint; add the property to `PLACEMENTS` in the script.

## Pick up a parser fix

easy-comb depends on the published [easy-gonz](../../easy-gonz/README.md) package. To ship a parser fix, release a new easy-gonz version first, then raise the `easy-gonz` range in `package.json` and run `npm install`.
