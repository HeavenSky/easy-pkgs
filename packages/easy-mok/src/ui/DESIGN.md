# 管理页设计规范

管理页(`src/ui/`)与悬浮条(`src/float/`)的统一样式约定. 基于 Tailwind CSS v4, 紧凑布局, 黑色为主色. 新增或修改界面时按本页取值; 本页没覆盖的情形先找最接近的已有写法.

## 字号

字号令牌在 `index.css` 的 `@theme` 中重定义, 比 Tailwind 默认小一档; 字号用 px, 行高用比值(目标行高 / 字号, 保留两位小数). 页面只用这五级, NEVER 写 `text-[13px]` 这类任意值, NEVER 用 `text-xl` 及以上.

| 令牌        | 字号 / 行高(比值) | 用途                                                                  |
| ----------- | ----------------- | --------------------------------------------------------------------- |
| `text-lg`   | 16px / 1.5(24px)  | 页面主体的主标题(例: 路由详情的路径), 每页最多一处                    |
| `text-base` | 14px / 1.43(20px) | Panel 与对话框的标题                                                  |
| `text-sm`   | 13px / 1.54(20px) | 默认: 正文, 列表项, 控件, 按钮, 标签页; `body` 已设为此级, 不必重复写 |
| `text-xs`   | 12px / 1.33(16px) | 辅助: 字段标签, 分区小标题, 表头, 说明文字, 次要元信息, 等宽的值      |
| `text-2xs`  | 11px / 1.45(16px) | 徽标(方法, 状态码, 来源标签), 计数                                    |

- 字重只用 `font-normal`, `font-medium`(标题, 标签, 选中项, 按钮), `font-semibold`(仅品牌名).
- 等宽字体(`font-mono`)用于路径, URL, 变量名与值, 请求头, 代码; 与正文同行时用 `text-xs`.
- 颜色层级: 正文 `text-zinc-900`, 次要 `text-zinc-500`, 更弱(占位, 计数, 时间) `text-zinc-400`.

## 间距

基于 Tailwind 的 4px 刻度, 只用以下几级:

| 刻度  | 像素 | 用途                                       |
| ----- | ---- | ------------------------------------------ |
| `0.5` | 2px  | 徽标之间, 图标与紧贴文字                   |
| `1`   | 4px  | 图标按钮组, 字段标签与控件                 |
| `1.5` | 6px  | 同一行的输入框之间, 列表行的元素之间       |
| `2`   | 8px  | 工具条内元素, 表单同一行字段               |
| `3`   | 12px | Panel 内边距, Panel 内分区之间, 侧栏内边距 |
| `4`   | 16px | 页面主体内边距, Panel 与 Panel 之间        |

- 容器内边距: 页面主体 `p-4`, Panel 内容 `p-3`, 对话框 `px-4 py-3`, 列表行 `px-3`.
- 纵向节奏用 `space-y-*` 或 `gap-*`, 只取 1.5 / 3 / 4 三档: 字段组内 `space-y-1.5`, Panel 内 `space-y-3`, Panel 之间 `space-y-4`.

## 尺寸

- 控件高度: 输入框, 下拉框与标准按钮 `h-7`(28px); 行内与 Panel 头部按钮 `h-6`(24px); 列表行 `h-8`; 表头 `h-8`; Panel 头部 `min-h-9`; 工具条 `min-h-10`; 页头 `h-11`.
- 图标(lucide): 标准按钮 14, 小按钮与行内 12, 页头品牌 16.
- 圆角: 控件与小卡片 `rounded-md`, Panel 与对话框 `rounded-lg`, 徽标 `rounded`.
- 侧栏宽度: 列表侧栏 `w-64`(窄屏 `w-56`), 右侧设置栏 `w-80`.

## 颜色

- 主色是黑: 主按钮, 选中的导航与标签页, 开关打开, 焦点轮廓都用 `zinc-900`(暗色模式 `zinc-100`). NEVER 用 sky / blue 表示选中, 主操作或链接.
- 中性色只用 zinc: 页面底 `zinc-50`, 面板 `white`, 边框 `zinc-200`, 控件边框 `zinc-300`, 行内分隔 `zinc-100`, 悬停底 `zinc-50`, 选中底 `zinc-100`.
- 语义色只表达状态: `emerald` 成功或正常, `amber` 警告, `rose` 错误与危险操作. 方法徽标沿用 `lib/utils.ts` 的 `METHOD_COLORS`.
- 链接: `text-zinc-900 underline decoration-zinc-300 underline-offset-2 hover:decoration-zinc-900`; 在等宽路径上可去掉下划线只保留悬停下划线.

## 布局与模块边界

页面由三种容器组成, 每个独立模块都必须落在其中之一里, NEVER 让内容直接漂在页面底色上:

1. **栏位(Pane)**: 页面级的列, 例如左侧列表栏, 右侧设置栏. 白底, 用 `border-r` / `border-l` 与主体分开, 顶部可接一条 `Toolbar`.
2. **Panel**(`components/ui/panel.tsx`): 主体里的模块. 白底, `border-zinc-200`, `rounded-lg`; 头部一行(`min-h-9`)放标题或标签页与操作, 用分隔线与内容隔开; 内容 `p-3 space-y-3`. 列表或表格放进 Panel 时用 `flush`, 由行自身的分隔线分隔.
3. **Toolbar**: 栏位或页面顶部的通栏工具条, 放搜索, 筛选与页面级操作.

- 有标签页的模块: 标签页放在 Panel 头部(`<Panel tabs={<Tabs inPanel ... />}>`), 选中标签的下划线压在头部分隔线上, 标签内容就是 Panel 的内容区. NEVER 把标签页条单独放在页面上而内容没有边界.
- Panel 内的分组用 `Section`(12px 小标题 + 内容), 不再嵌套带边框的卡片; 确需嵌套时内层用 `rounded-md border-zinc-200` 且不加阴影.
- 主体区: `bg-zinc-50`, `p-4`, Panel 之间 `space-y-4`; 主体内容最大宽度不限制, 表单字段自身控制宽度.
- 右侧设置栏的分区用可折叠的分区头(全宽, `border-b`), 不用 Panel.
- 顶部提示条用 `Notice`(`components/ui/state.tsx`), 一行, 超长时截断并把全文放进 `title`.

## 列表与表格

- 侧栏列表项用 `listItemClass(selected)`: 选中为浅灰底, 左侧 2px 黑色竖条, `font-medium`; 行高 `h-8`(两行内容时 `py-1.5`).
- 行内操作按钮默认透明, 悬停或聚焦行时显示; 用 `opacity-0` 而不是 `hidden`, 保持键盘可达.
- 表格: 表头 `h-8 text-xs font-medium text-zinc-500 bg-zinc-50 border-b`; 行 `h-8 border-b border-zinc-100`, 悬停 `bg-zinc-50`, 选中 `bg-zinc-100`.

## 键值对

- 编辑态用 `KV_ROW` / `KV_ROW_CHECK`(`components/ui/kv.tsx`): 键列窄(最小 6rem), 值列宽(1:2.5), 末列删除按钮. NEVER 给键输入框固定 `w-40` 而让值输入框挤压.
- 只读态用 `KvList`: 键列按内容自适应且最宽 12rem, 值列换行显示全文.

## 只读优先

已保存的配置类内容默认以只读形式展示, 点 Panel 头部的「编辑」切到输入框, 编辑态头部显示「取消」与「保存」(`EditActions`). 取消丢弃未保存修改.

- 适用: 改动频率低, 展示多于编辑的配置(环境组的名称, 展示名, 权重与变量; 快照的名称, 展示名, 权重, 变量与 set-cookie 设置; 快照脱敏规则; 场景组的成员与覆盖).
- 不适用: 工作区里需要反复修改的内容(调试请求编辑器, 新建与导入对话框, 场景内容编辑器), 以及单个即时生效的开关与下拉框.
- 只读展示时值用 `KvList` 或纯文本, 空值显示 `—` 或「暂无」.

## 按钮

- 变体: `default`(黑底, 每个区域最多一个主操作), `outline`(次要操作), `ghost`(工具条与行内操作), `danger`(确认对话框中的删除).
- 尺寸: `md`(h-7, 表单与工具条), `sm`(h-6, Panel 头部与行内), `icon`(28px), `icon-sm`(24px).
- 纯图标按钮必须有 `aria-label`, 并用 `title` 给出同样的提示.

## 表单

- 字段用 `Label` 包住控件(标签在上), 字段间 `gap-2`; 说明文字用 `Hint`.
- 同一行多个字段用 `flex gap-2` 或 `grid`, 数字类短字段给固定宽度(`w-20`), 文本字段占满.
- 长说明收进 `<details>`, 摘要写成「说明」或具体问题, `text-xs text-zinc-500`.

## 可访问名称

按钮, 标签页, 输入框的可访问名称(文字或 `aria-label`)是测试与 e2e 的定位依据. 改样式时保持名称不变; 确需改名时同步改 `test/ui/` 与 `test/e2e/run.mjs`.
