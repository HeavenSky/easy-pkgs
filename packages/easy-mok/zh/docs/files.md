# 提交管理页写入的文件

[English](../../docs/files.md) · **简体中文**

读完本页，你会知道管理页会创建哪些文件，哪些应该进版本库。在浏览器里新建的场景和路由写进 mock 目录，方便共享；运行状态留在仓库之外。

| 文件                                      | 内容                                                   | 是否提交                           |
| ----------------------------------------- | ------------------------------------------------------ | ---------------------------------- |
| `<mock 目录>/__scenes__/*.json`           | 管理页新建或录制的场景，每个路由一个文件               | 建议提交                           |
| `<mock 目录>/__scenes__/<场景文件名>/` | 该路由文件场景的响应体文件；删除使用它的场景时一并删除 | 建议提交 |
| `<mock 目录>/__gui__.json`                | 管理页新建的路由                                       | 建议提交                           |
| `<mock 目录>/__debug__/requests/__refs__.json` | 哪些场景引用了哪些调试快照；每次路由重载时由 `__scenes__/` 重建 | 提交；合并冲突时删掉即可重建 |
| `<mock 目录>/__debug__/` | 调试页的请求、环境组与敏感值来源 | 部分提交；见[在管理页调试真实接口](debug.md#提交调试页写出的文件) |
| `node_modules/.cache/easy-mok/state.json` | 手选场景、延迟、状态码、场景组、全局开关、请求忽略规则与调试页激活的环境组 | 不提交；删除 `node_modules` 后重置 |

状态文件的位置可以用 `stateFile` 选项修改，见[选项与环境变量](options.md)。

## 回放保存的路由与场景

`__gui__.json` 中值为 `null` 的路由回放 JSON `null` 响应体。存为场景的空响应（如 204，或没有响应体的 DELETE）回放空响应体。

## 修复手改坏的 `__gui__.json`

`__gui__.json` 不是合法的 JSON 对象时（例如手改后留了尾逗号），管理页拒绝修改它，不会覆盖你改过的内容。管理接口返回错误码 `GUI_FILE_INVALID`；修好或删除该文件后重试。

## 新建路由加载失败时

管理页新建的路由未能加载时，easy-mok 把 `__gui__.json` 和该路由的场景文件还原为写入前的内容，不留坏记录。管理接口返回错误码 `LOAD_ERROR`、说明原因的消息与相关诊断。
