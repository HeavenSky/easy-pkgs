# Migrate from npminstall

**English** · [简体中文](../zh/docs/migrate-from-npminstall.md)

Four steps move a project from [cnpm/npminstall](https://github.com/cnpm/npminstall) to easy-np, whose code is derived from npminstall 8.0.1; install easy-np first ([Install and choose an entry point](install.md)).

## Switch a project

1. Delete the `node_modules` that npminstall installed: easy-np treats it as unfinished.
2. Copy your settings from `~/.cnpmrc` into `~/.nprc`, and rename `config.npminstall` in `package.json` to `config.np`.
3. Replace commands and options in your scripts using the tables below; a removed command-line option makes easy-np exit with an error that names its replacement.
4. Install: `np`. You should see: the same defaults as npminstall, with no lockfile and all dependency scripts running; move to `np-x install` when you want a lockfile and script review ([Choose np or np-x install](install.md#choose-np-or-np-x-install)).

## Rename commands, files and settings

| Item                  | npminstall                                                                          | easy-np                                                                        |
| --------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Package and commands  | package `npminstall`; commands `npminstall`, `npmlink`, `npmuninstall`, `npmupdate` | package `easy-np`; commands `np` and `np-x`                                    |
| User config file      | `~/.cnpmrc`                                                                         | `~/.nprc`, shared with easy-npd                                                |
| Cache directory       | `~/.npminstall_tarball`, environment variable `npminstall_cache`                    | `~/.np_tarball`, environment variable `np_cache`; both read `npm_config_cache` |
| `package.json` config | `config.npminstall`                                                                 | `config.np`                                                                    |
| Install-done marker   | `__npminstall_done` in each package's `package.json`                                | `node_modules/.store/.np-state.json`                                           |
| User-Agent            | `npminstall/<version>`                                                              | `easy-np/<version>`                                                            |

## Expect these behavior differences

Features npminstall already had, where the behavior differs in a way that affects you:

| Item                               | npminstall                                                                                              | easy-np                                                                                                                                                                                                                                                                   |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Install failure                    | stops at the first error                                                                                | installs the other packages; the next run resumes ([Resume a failed install](resume.md))                                                                                                                                                                                  |
| Packages hoisted to the root       | always hoists packages whose names match eslint, prettier, babel                                        | hoists nothing by default ([Decide what is hoisted](workspaces.md#decide-what-is-hoisted))                                                                                                                                                                                |
| Version of hoisted links           | keeps an existing link                                                                                  | always the highest version in this install's tree; dependencies declared in the root `package.json` keep their declared version                                                                                                                                           |
| Missing peerDependencies           | only warns                                                                                              | installed automatically, as in npm 7+; a failure skips them like optional dependencies                                                                                                                                                                                    |
| Version selection                  | ignores `engines`                                                                                       | prefers versions whose `engines.node` matches, as npm does                                                                                                                                                                                                                |
| Tarball integrity check            | sha1 only                                                                                               | the strongest algorithm in `dist.integrity`                                                                                                                                                                                                                               |
| Registry credentials               | the `.nprc` username and password are added by substring match, and to every request with `always-auth` | the `.npmrc` `_authToken` and the `.nprc` username and password go only to requests on the registry's host; `always-auth` has no effect                                                                                                                                   |
| `np-x uninstall`                   | keeps hoisted links; may return before `package.json` is written                                        | removes hoisted links nothing uses; returns after `package.json` is written                                                                                                                                                                                               |
| Git dependencies                   | fetched through pacote, built with `npm install`                                                        | fetched with the git CLI (git must be installed), build dependencies installed by np itself                                                                                                                                                                               |
| Local folder dependencies          | `npm pack`, copying the whole folder on failure                                                         | trusted folders (declared by the root project or a workspace, see [Which scripts need approval](allow-scripts.md#which-scripts-need-approval)) use `npm pack` with npm >= 7.18; otherwise files are copied by the `files` and `.npmignore` rules, without running scripts |
| Damaged tgz in the cache           | every retry reads the same bad file                                                                     | deleted and downloaded again                                                                                                                                                                                                                                              |
| Repeated single-value options      | some take the first value, some become an array and fail                                                | the last value wins, as in npm; `--allow-scripts`, `--only`, `--include`, `--omit` merge all values                                                                                                                                                                       |
| `--from-package-lock` load failure | warns and resolves from the network                                                                     | exits with an error                                                                                                                                                                                                                                                       |
| `--offline`                        | still goes to the network on a cache miss                                                               | reads only the disk cache and sends no request                                                                                                                                                                                                                            |
| `--proxy`, `--strict-ssl`          | have no effect                                                                                          | applied, and passed to install scripts, node-gyp and git                                                                                                                                                                                                                  |

## Replace removed commands and options

A removed command-line option makes easy-np exit with an error that names the replacement; removed environment variables and `package.json` settings (such as `npm_china` and `config.npminstall.*`) are no longer read and cause no error.

| Item                                                                       | What it did                                            | Now                                                                                                                |
| -------------------------------------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| commands `npminstall`, `npmuninstall`, `npmupdate`, `npmlink`              | one command per feature                                | `np` and `np-x <command>`                                                                                          |
| `-S/--save`                                                                | save to `dependencies`                                 | removed; saving to `dependencies` is the default                                                                   |
| `-D/--save-dev`, `-O/--save-optional`                                      | save to that field                                     | `--write=dev`, `--write=optional`; `np-x uninstall` uses `--write` as well                                         |
| `-E/--save-exact`                                                          | save the exact version                                 | `--write-exact`                                                                                                    |
| `--client`, `--save-client`, `--save-build`, `--save-isomorphic`           | install or save cnpm's three extra dependency fields   | `--only`, `--include`, `--write=<type>`; these three fields are not installed by default                           |
| `--no-optional`, `--legacy-peer-deps`                                      | skip optional dependencies, do not install peers       | `--omit=optional`, `--omit=peer`                                                                                   |
| `--production` disabling the disk cache, `--cache-strict`                  | no cache in production mode                            | removed; `--production` uses the cache, pass `--no-cache` to skip it                                               |
| `--root`, `-w`, `--workspace`                                              | choose the project directory or a workspace            | removed; run the command in that directory                                                                         |
| `--dedup`                                                                  | flat hoisting (an early easy-np option)                | renamed `--shamefully-hoist`                                                                                       |
| `--lockfile-path`                                                          | install from a package-lock.json                       | renamed `--from-package-lock`                                                                                      |
| `-d`                                                                       | short for `--detail`                                   | removed; use `--detail`                                                                                            |
| `--fetch-only`, `--rebuild`                                                | fetch and rebuild as install options                   | removed; use `np-x fetch`, `np-x rebuild`                                                                          |
| `--dependencies-tree`, `--save-dependencies-tree`                          | install from or save a dependency tree file            | removed; replaced by `np-lock.json`                                                                                |
| `--flatten`, `--fix-bug-versions`, `--tarball-url-mapping`                 | dependency version fixes and tarball address rewriting | removed                                                                                                            |
| `-c`, `--china`, `npm_china`                                               | switch to npmmirror and the binary mirror              | removed; replaced by [automatic switching](registry.md#let-easy-np-switch-public-registries)                       |
| `--custom-china-mirror-url`                                                | replace the binary mirror address                      | removed                                                                                                            |
| `--prune`, `config.npminstall.prune`, `env:production` / `env:development` | skip files from a fixed list when extracting           | removed: the list includes `tsconfig.json`, `LICENSE` and more, and silently breaks packages such as `@tsconfig/*` |
| `--force-link-latest`                                                      | overwrite existing hoisted links with a higher version | removed; the highest version is always linked                                                                      |
| `--disable-fallback-store`                                                 | turn off the `.store/node_modules` fallback links      | removed; the fallback links are always created                                                                     |
| `np-x uninstall --ignore-scripts`                                          | declared but had no effect                             | removed and rejected with an error; uninstall runs no lifecycle scripts                                            |
| `.npmrc` `np-public-hoist-pattern`                                         | hoist pattern in `.npmrc`                              | removed; use `public-hoist-pattern` or `config.np.publicHoistPattern`                                              |
